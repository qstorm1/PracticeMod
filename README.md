# Minecraft Jujitsu Kaisen Mod

## Setup
Mod is located in build/libs/practice-mod-1.0.0.jar Requires Minecraft 1.21.11 fabric, if you don't know how to get fabric follow [this tutorial](https://www.youtube.com/watch?v=RpN94a2q8JI)
If you just want to try the mod yourself, check out the releases to get a fake minecraft instance going (It's a little complex to do though)

Make sure to install all dependencies listed below
### Dependencies
 - [Cardinal Components](https://modrinth.com/discover/mods?q=Cardinal%20C)
 - [Player Animation Library](https://modrinth.com/discover/mods?q=Player%20Animation)
 - [Fabric API](https://modrinth.com/mod/fabric-api?version=1.21.11&loader=fabric)



## Powers 


**pick the keybinds that work best for you, I chose:**

- attack.jjk.1 = z
- attack.jjk.2 = x
- attack.jjk.3 = c
- attack.jjk.4 = v

Note that this mod has not been tested in multplayer
#### Limitless
To give yourself limitless, search for soul in the creative mode hotbar and click the potion, when you drink it you will be given the ability (this is temporary)
1) press j: activates limitless innate ability which prevents most entities from approching the player
2) combo 1 z-c-v: activates a power that attracs entities towards it
3) combo 2 z-z-v-v-c: activates a power that repels enemies
4) combo 3 x-v-v-c: activates an ability that destroys all entities (including invunrable ones)
5) press ; : activate domain which sends enemies to the domain world where they have weakness
